# Smart Food-Sorting Robotic Arm

I designed and built a robotic arm that automatically sorts food packaging based on whether it has been opened or remains unopened. The system analyzes hue and brightness values to distinguish between the two categories and determines where the robotic arm should turn and place each item. Opened packaging is directed toward the trash, while unopened food is placed in a separate location.

I developed this project for the Georgia Student Technology Competition (GASTC), where I earned **3rd place**. Through this project, I explored robotics, automated decision-making, and how technology can be used to improve waste sorting.
